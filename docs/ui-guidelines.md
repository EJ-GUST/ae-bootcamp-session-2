# TODO App UI Guidelines

## Layout and responsiveness
- Keep the task list and primary actions easy to find.
- Use a simple, consistent layout that adapts to mobile and desktop screens.
- Group related controls and provide a clear visual hierarchy.

## Visual consistency
- Use a high-contrast color palette and consistent styles for buttons and text.
- Clearly distinguish completed tasks from active tasks without relying on color alone.
- Use consistent spacing and typography throughout the app.

## Interaction and feedback
- Clearly label actions for adding, editing, completing, and deleting tasks.
- Show helpful feedback when actions succeed or fail, and when input is invalid.
- Make destructive actions clear to help prevent accidental deletion.

## Accessibility
- Use semantic HTML and accessible names for interactive controls.
- Ensure all functionality is keyboard accessible and focus indicators are visible.
- Associate form labels with inputs and provide sufficient text contrast.
- Announce important updates to assistive technologies.
