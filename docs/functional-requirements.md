# TODO App Functional Requirements

## Task management
- Users can add a task with a required title.
- Users can edit a task’s title and due date.
- Users can mark a task complete or incomplete.
- Users can delete a task.
- The app provides clear feedback when required information is missing.

## Due dates and ordering
- Users can optionally set or change a task’s due date.
- Due dates are displayed for tasks that have them.
- Users can sort tasks by due date; tasks without a due date appear last.

## Persistence
- Tasks and changes remain available after the app is refreshed or reopened.
